# SICU LINK

외과계 중환자실의 병상 현황, 환자 기록, 간호 인력과 입실 준비 과정을 함께 살펴볼 수 있는 웹 시연 프로젝트입니다.

[사이트 이용](https://yerinx.github.io/sicu-link/) · [입실 준비 시연](https://yerinx.github.io/sicu-link/admission-story.html) · [운영 설계 검토](https://yerinx.github.io/sicu-link/ops-ax-review.html)

## 주요 기능

- 병동 현황: 병원·중환자실별 병상 배치, 재실·공실·예약 상태, 근무 인력과 업무 현황을 표시합니다.
- 환자 기록: 선택한 환자의 입원 정보, 활력징후 추이, 연결 장비와 평가 시점별 기록을 조회합니다.
- 검사·영상: 검사명과 코드로 결과를 검색하고, 검사 이력과 영상 설명을 확인합니다.
- 환자 상담: 선택한 환자 기록을 바탕으로 상태 요약, 확인 항목, 인계용 SBAR 구성 과정을 시연합니다.
- 병상 운영: 월별 병상 흐름과 입실 준비, 전실·병상 정리·예약·입실 순서를 재생합니다.
- LINK 시연: 대기 환자의 입실 요청부터 조건 확인, 보고, 담당자 검토와 후속 업무까지 진행합니다.
- 표시 설정: 한국어·영어 전환, 큰 글씨와 모바일 화면을 지원합니다.

## 이용 방법

1. 사이트에서 병원 상황판 또는 통합 관제를 선택합니다.
2. 병원 상황판에서는 병원과 병동을 선택한 뒤 병상을 눌러 환자 상세를 확인합니다.
3. 환자 상세의 기록·이력, 검사실, 영상·검사, AI 상담 탭에서 필요한 항목을 조회합니다.
4. 병동 화면의 재생 모드에서 월별 병상 흐름을 살펴보거나, LINK 에이전트에서 입실 준비 시연을 진행합니다.

별도 설치나 로그인 없이 웹 브라우저에서 이용할 수 있습니다.

## 시연 범위

환자 정보, 검사 결과와 예측값은 시연용 가상 자료입니다. 상담은 준비된 시연 응답을 제공하며 실제 모델 추론은 실행하지 않습니다. 영상 화면의 흉부 그림은 설명용 도식입니다. 실제 병원 시스템이나 환자 기록에는 연결되어 있지 않습니다.

## 로컬 실행

저장소를 내려받은 폴더에서 다음 명령을 실행합니다.

```sh
python -m http.server 8080
```

브라우저에서 [http://localhost:8080/](http://localhost:8080/)에 접속합니다.

## 프로젝트 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 상황판 진입 화면 |
| `ui/` | 환자 상세, 기록 조회, 병상 운영과 LINK 시연 |
| `static/` | 화면의 공통 동작과 스타일 |
| `assets/` | 글꼴, 아이콘과 도식 |
| `snapshot.json`, `scenarios/` | 가상 상태와 시나리오 자료 |
| `admission-story.html` | 입실 준비 시연 화면 |
| `ops-ax-review.html` | 운영 설계 검토 자료 |

정적 HTML, CSS, JavaScript로 구성되며 GitHub Pages에서 제공됩니다.
